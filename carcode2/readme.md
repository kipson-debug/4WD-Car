Hello everyone. 
First of all, I would like to thank you for your interest in this project. This is a simple Arduino code that allows you to control a 4WD K-CAR using an IR remote control. 
The code is designed to be easy to understand and modify, so feel free to experiment and make it your own.
So, here's is what you need to get started:
1. An arduino UNO
2. 4 dc motors that are connected to the motor driver
3. An IR receiver module
4. An IR remote control
5. A power source for the motors (like a battery pack)
6. The Arduino IDE installed on your computer
7. The IRremote library installed in the Arduino IDE (you can install it via the Library Manager)
8. The code in the repository
9. You can find the circuit diagram through the link below:
                 https://www.tinkercad.com/things/djLFsLPM5Cu-san-means-dr-bayel?sharecode=JswQdEoPzYC3WXvUTiRdgQ2V8vrFFA7o2XOZFL_SAuM
                 
This code doesn't work on tinkercad but it will compile and work on a real arduino board.
